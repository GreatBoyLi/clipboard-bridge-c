# Caps Lock Implementation Plan

**Goal:** 实现已确认的单键短按/1 秒长按规则，以 Windows 大写锁定为准。
**Architecture:** 纯 C 按住状态机，Mac IOHID 物理边沿 + 既有事件监听抑制，认证连接携带独立动作确认；Windows 输入线程处理真实状态和原生组合。
**Tech Stack:** C11, AppKit/IOKit, Windows keyboard hook/SendInput。

- [x] 先测短按、1000ms 边界、长按一次、重复 down、换前台、断线/设备移除及时间倒序，再实现 caps_hold.h。
- [x] Mac 原生 HID 接口只读取 Caps Lock；可选开关、权限诊断、释放所有监听资源，模拟接口验证不触碰真实键盘。
- [x] 键盘线程统一处理计时和队列，网络主线程取请求前再检查前台及 TTL。修饰键或其它组合取消。默认配置不改变。
- [x] Windows 子任务实现专用消息线程及动作，验证短按的两种状态、长按、失败与按键释放。只有确认成功才回报完成。
- [x] 协议 ENABLE/READY/ACTION/RESULT，独立递增序号和超时，断线清队列；先测错误序号及旧端未就绪无动作。
- [x] Mac 构建、全部回归、Windows 原生模拟测试加入 ASCII/CRLF 构建脚本；独立复核后安装、提交本地 Git，不推送。Windows 原生编译留给用户实机验证。
