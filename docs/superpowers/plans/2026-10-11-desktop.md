# Desktop UI and host-selected Mac pairing

Goal: double-click Mac app / Windows tray, no startup service. Windows stores separate 64-hex keys for named Macs and runs only the selected credential. Switching waits for graceful child exit before listening with the next key. Existing session baseline prevents old clipboard forwarding.

Architecture: native UI supervisors launch bundled existing worker. A private inherited stdin pipe (`--desktop-control`) requests graceful shutdown and detects parent exit; worker owns clipboard/input on its existing thread. Per-device key import/export provides explicit pairing without a new network protocol. Pairing files go only to the corresponding Mac. Native state is persistent in user configuration directories. No raw clipboard contents or keys appear in UI logs.
